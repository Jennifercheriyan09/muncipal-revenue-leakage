# Frontend

Next.js 15 + Tailwind + React Leaflet GIS dashboard for the Municipal Revenue Leakage Intelligence System.

## Run

```bash
npm install
npm run dev
```

```text
http://localhost:3000
```

- Day 6: Live GIS map with ward boundaries, colour-coded property risk markers, clickable property detail popups, and heatmap toggle. Powered by PostGIS backend.
